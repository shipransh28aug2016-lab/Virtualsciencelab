# Guru on Android

`guru/android/` is generated by Capacitor (`npm run android:sync`, which runs `npx cap add android` the first time) and is built in CI by `.github/workflows/guru-android.yml`. Edit `tools/android-patch.mjs` for manifest changes rather than hand-editing generated files.

## Permissions
`tools/android-patch.mjs` adds `INTERNET`, `RECORD_AUDIO`, `MODIFY_AUDIO_SETTINGS`, an optional microphone feature and a `RecognitionService` query (needed on Android 11+ to find the speech service).

## Local build
```
cd guru
npm install
npm run android:sync
node tools/android-patch.mjs
cd android && ./gradlew assembleDebug     # app/build/outputs/apk/debug/app-debug.apk
```
Needs Node 18+, JDK 17, Android SDK (platform 34, build-tools 34).

## Speech recognition inside the WebView
Android System WebView does not implement the Web Speech API `SpeechRecognition`. Text-to-speech (`speechSynthesis`) usually works. Guru's voice service must feature-detect: if `window.SpeechRecognition || window.webkitSpeechRecognition` is missing and `window.Capacitor?.Plugins?.SpeechRecognition` exists, use the plugin instead:
```js
const SR = window.Capacitor.Plugins.SpeechRecognition;
await SR.requestPermissions();                       // RECORD_AUDIO
const { available } = await SR.available();
SR.addListener('partialResults', (e) => onInterim(e.matches[0]));
const { matches } = await SR.start({ language: 'hi-IN', partialResults: true, popup: false });
// stop with SR.stop(); remove listeners afterwards
```
Install: `npm i @capacitor-community/speech-recognition` (already an optionalDependency) then `npm run android:sync`. If neither exists, the UI falls back to typing (and the Android keyboard's own mic button).

## TWA (Trusted Web Activity) alternative
A TWA runs the published PWA in Chrome (full Web Speech support, smaller APK). Requires the site on HTTPS (GitHub Pages is).
1. Publish Pages and confirm `https://<user>.github.io/<repo>/guru/manifest.webmanifest` loads.
2. `npm i -g @bubblewrap/cli`, then `bubblewrap init --manifest https://<user>.github.io/<repo>/guru/manifest.webmanifest` and `bubblewrap build` (creates a signing key; keep it safe).
3. Get the key fingerprint: `keytool -list -v -keystore android.keystore` (SHA-256).
4. Digital Asset Links must be served from the **origin root**: `https://<user>.github.io/.well-known/assetlinks.json`. That is only possible with a user/org site (`<user>.github.io` repo) or a custom domain. Copy `guru/.well-known/assetlinks.json.template` to `assetlinks.json`, set `package_name` and your fingerprint. On a project page (`/<repo>/`) verification cannot succeed and Chrome shows a URL bar; use the Capacitor APK instead.
