# License notes

Guru itself has no third-party runtime dependencies: all code in `guru/src` is first-party vanilla ES modules.

Build/deploy tooling only (not shipped in the web app):
- `@capacitor/core`, `@capacitor/cli`, `@capacitor/android` (MIT) for the Android wrapper.
- `@capacitor-community/speech-recognition` (MIT), optional, Android WebView speech input.
- GitHub Actions: `actions/checkout`, `setup-node`, `setup-java`, `upload-artifact`, `upload-pages-artifact`, `deploy-pages`, `configure-pages` (MIT), `android-actions/setup-android` (MIT).
- Android SDK / Gradle are subject to Google's and Gradle's own licenses at build time.

Fonts: the UI uses system / locally installed Noto Sans Devanagari with system fallback; no font files are bundled by the deploy layer. Icons in `assets/icons` are generated by `tools/make-icons.mjs` and are original to this project.

CBSE curriculum data is read from the repository's `data/curriculum` and remains subject to the terms of its source (CBSE publications). Teachers should verify against the latest official circular.
